Resource Profile: HL7® AT Scheduling Slot Profile

Official URL: http://hl7.at/fhir/TC-FHIR-AG-Scheduling-R5/R5/StructureDefinition/at-scheduling-slot Version: 0.2.0
Draft as of 2026-01-12 Responsible: HL7® Austria, TC FHIR® Computable Name: HL7ATSchedulingSlot

HL7® Austria FHIR® Scheduling Profile for slot data in Austria.

This Profile is used in the Find available Slots for potential Appointments.

Usages:

  • Refer to this Profile: HL7® AT Scheduling Appointment Profile
  • Examples for this Profile: Slot/HL7ATSchedulingSlotExample01-free, Slot/HL7ATSchedulingSlotExample02-VirtualVisit, Slot/HL7ATSchedulingSlotExample03-selectable-encounterClass and Slot/HL7ATSchedulingSlotExample04-external-booking-URL

Resource Profile: HL7® AT Core RelatedPerson Profile

Official URL: http://hl7.at/fhir/HL7ATCoreProfiles/5.0.0/StructureDefinition/at-core-related-person Version: 2.1.0
Active as of 2025-09-07 Responsible: HL7® Austria, TC FHIR® Computable Name: HL7ATCoreRelatedPerson

HL7® Austria FHIR® Core Profile for a related person in Austria. The HL7® AT Core RelatedPerson is based upon the core FHIR® RelatedPeson Resource and designed to meet the applicable demographic data elements in Austria. Note, this extension represents the common structure of a person information within Austrian information systems.

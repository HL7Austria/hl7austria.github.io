OperationDefinition: e-Diagnose Operation für List-Write

Official URL: https://fhir.hl7.at/elga/ediag/r4/OperationDefinition/at-ediag-operation-listwrite Version: 0.1.0
Draft as of 2026-08-14 Responsible: ELGA GmbH Computable Name: AtDiagListWrite

Die $list-write Operation wird aufgerufen, wenn eine Liste geschrieben wird.

URL: [base]/Condition/$write

URL: [base]/Procedure/$write

URL: [base]/AllergyIntolerance/$write

Parameters

UseNameScopeCardinalityTypeBindingDocumentation
INid1..1string

Der id Parameter dient der Zuordnung des Patienten.

INlist1..1Bundle

Der list Parameter dient der Übermittlung der Liste des Patienten.

OUTreturn0..1Resource (OperationOutcome)

Der return Parameter gibt Auskunft über den Erfolg der Operation.

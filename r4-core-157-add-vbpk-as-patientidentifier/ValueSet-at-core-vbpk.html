ValueSet: HL7AT Core vbPK

Official URL: https://fhir.hl7.at/core/r4/ValueSet/at-core-vbpk Version: 2.1.0
Active as of 2026-08-21 Responsible: HL7® Austria, TC FHIR® Computable Name: HL7ATCoreVBPK

This value set contains the OIDs for the vbPK (Verschlüsseltes bereichsspezifisches Personenkennzeichen) in Austria according to E-Government-Bereichsabgrenzungsverordnung – E-Gov-BerAbgrV.

References

  • HL7® AT Core Patient Profile
  • HL7® AT Core Practitioner Profile

This value set was designed for the HL7AT Core IGs (R4 and R5) and will be moved to the Austrian e-Health terminology server, depending on the outcome of the ballot.

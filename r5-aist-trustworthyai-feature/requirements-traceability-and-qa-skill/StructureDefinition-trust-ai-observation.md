## Resource Profile: Trust AI Generated Observation 

| | |
| :--- | :--- |
| *Official URL*:http://example.org/fhir/trust-ai-transparency/StructureDefinition/trust-ai-observation | *Version*:0.1.0 |
| Draft as of 2026-10-02 | *Computable Name*:Trust_AIObservation |

 
An Observation profile representing a clinical output generated by an AI system, including AI-related transparency metadata and links to the relevant patient, encounter, and AI system. 

### Regulatory Requirements

This profile is part of the **AI Output Context** layer. It implements the following documentation requirements from the [Requirements Traceability](requirements.md) analysis.

| :--- | :--- | :--- | :--- |

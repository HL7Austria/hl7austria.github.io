## Terminology

# Terminology

The Implementation Guide defines custom terminology where existing FHIR terminologies do not sufficiently represent AI transparency concepts.

## Code Systems

The IG defines custom CodeSystems for:

* EU AI transparency concepts
* Human oversight actions
* GDPR legal bases
* GDPR Article 9 exceptions
* EHDS concepts

## Value Sets

The following ValueSets are provided:

* AI Performance Metrics
* Clinical Validation Status
* Data Quality
* EHDS Usage Category
* EHDS Data Category
* EHDS Secondary Use Purpose
* Case-Specific Indications

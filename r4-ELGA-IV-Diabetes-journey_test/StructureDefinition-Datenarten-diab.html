Logical Model: Datenarten für das versorgungsstufenübergreifende elektronische Leitdokument

Official URL: https://fhir.hl7.at/elga-iv-diabetes-r4/StructureDefinition/Datenarten-diab Version: 0.1.1
Draft as of 2025-08-11 Responsible: ELGA GmbH Computable Name: DatenartenDiab

Datenarten für das Versorgungsstufenübergreifende elektronische Leitdokument basierend auf dem Rahmenkonzept Integrierte Versorgung Diabetes mellitus Typ 2.

Refer to the ​mapping from the logical model of diabetes to the logical model based on the International Patient Summary (IPS) in order to get an idea how the IPS can be used in this context.

Usages:

  • This Logical Model is not used by any profiles in this Implementation Guide
